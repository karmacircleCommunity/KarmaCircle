# What is NgoWorld ?

NgoWorld is a hub to **connect** NGOs, Charities, and people across the world to **collaborate** and **build** a better tomorrow.  
Sign up as an organization or user and be a cause for change.

⭐ **Don’t forget to drop a star if you like the project.**

> Remember, **a good PR makes you a good contributor**.

We at NgoWorld maintain a clean and consistent codebase.  
Please follow **conventional pull request titles and commit messages**.

⚠️ PRs without proper templates, guidelines, or relevant changes may be closed or flagged as spam.
